# Insurance Risk Analytics

## Project Overview
This project analyzes insurance portfolio data to identify risk patterns,
claim behavior, profitability trends, and regional differences.

## Objectives
- Build reproducible analytics pipeline
- Perform exploratory data analysis
- Assess portfolio profitability
- Discover claim trends and outliers

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- GitHub Actions
